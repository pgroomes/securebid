# SecureBid CRM Demo

Mobile-first demo of SecureBid CRM, quoting, work orders, technician profiles, pricing, branding, customer portal, read receipts, and QuickBooks simulation.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload the **contents of this folder** to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then save.
6. Open the GitHub Pages address shown in the Pages settings.

The home page is `index.html`.

## Important

This package is a front-end demonstration. Data is stored in the browser using localStorage. It does not yet provide production authentication, shared cloud data, server-side PDFs, secure customer links, live email delivery, or live QuickBooks synchronization.

Do not add passwords, API secrets, QuickBooks credentials, or customer-sensitive production data to this repository.
